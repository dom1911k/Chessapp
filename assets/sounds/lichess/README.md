# Lichess sound recordings

`Move.mp3`, `Capture.mp3` and `Error.mp3` are from the "standard" sound set of
[Lichess](https://lichess.org) (lichess-org/lila, `public/sound/standard`), licensed
**AGPLv3 or later**. Chess Coach is GPLv3; GPLv3 §13 allows combining it with AGPLv3 works.

The app's "Standard" sounds in `public/sounds/standard/` are made from these recordings by
`scripts/make-sounds.sh` (filtering, small pitch changes and layering) and carry the same licence.
